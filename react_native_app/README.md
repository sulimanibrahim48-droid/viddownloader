# 📱 Playlist Stitcher - React Native Mobile App

تطبيق موبايل مخصص للهواتف الذكية (Android & iOS) مبني باستخدام **React Native + TypeScript**.

## 🚀 المميزات (Features)

- **واجهة عصرية بنمط ليلي (Dark Theme)** مصممة خصيصاً لتناسب شاشات الموبايل (Android و iOS).
- **التحميل ودمج القوائم (Playlists)**: إمكانية إدخال رابط القائمة واختيار جودة الفيديو أو الصوت (MP4 أو MP3).
- **متابعة لحظية بالبث المباشر (Real-time SSE Progress)**: شريط تقدم متزامن مع الخادم بنسبة مئوية دقيقة وتفاصيل حالة العملية.
- **عارض الأوامر والمخرجات (Live Logs)**: استعراض مخرجات `yt-dlp` و `FFmpeg` أولاً بأول.
- **حفظ ومشاركة مباشرة**: حفظ الفيديو المدمج على الذاكرة أو ألبوم الصور أو مشاركته مع التطبيقات الأخرى (WhatsApp, Telegram, etc).
- **إعدادات السيرفر المتنقلة (Server Settings)**: إمكانية تغيير عنوان السيرفر والاتصال بالكمبيوتر أو السيرفر السحابي بضغطة زر مع فحص الاتصال.

---

## 🛠️ متطلبات التشغيل (Prerequisites)

1. تثبيت الحزم:
   ```bash
   cd react_native_app
   npm install
   ```

2. تشغيل السيرفر الخلفي (Backend) في مجلد `webapp`:
   ```bash
   cd webapp
   python app.py
   ```

3. تشغيل تطبيق الموبايل:
   ```bash
   cd react_native_app
   npx expo start
   ```

4. **التجربة على هاتفك المباشر:**
   - قم بتثبيت تطبيق **Expo Go** من متجر Google Play (للأندرويد) أو App Store (للآيفون).
   - امسح رمز الـ QR الظاهر في الطرفية (Terminal) بكاميرا هاتفك أو تطبيق Expo Go.
   - سيعمل التطبيق مباشرة على شاشة هاتفك!
